# Gappy’s File

Portfolio site. Plain HTML/CSS/JS, hosted on GitHub Pages.

- `js/data.js` — the list of projects (titles, images, texts). Edit this to add or reorder work.
- `assets/projects/<project>/1.jpg, 2.jpg…` — images, in the order they appear.
- `assets/creature.svg` — illustration on the home page.
- `assets/about/face.svg` — illustration on the About page.
